bear-app-rag Benchmark Results

Semantic (RAG) vs keyword (SQLite LIKE) retrieval on a 25-note synthetic corpus with 23 eval queries across 7 query types.

Key finding: Semantic search improves recall by 40% on paraphrase queries and 13% on synonym queries. Exact-match recall ties at 1.00; the multi-concept group favors semantic recall and keyword first-hit rank.

Data source: tests/eval/results.json. Reproduce with uv run pytest -m eval -v.
