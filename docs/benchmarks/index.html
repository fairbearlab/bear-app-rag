bear-app-rag Benchmark Results

RAG vs keyword (SQLite LIKE) retrieval on a 25-note synthetic corpus with 20 eval queries across four query types.

Key finding: Semantic search beats keyword matching by +40% recall on paraphrase queries and +13% on synonym queries. On exact-match queries (control), both tie at 1.00.

Data source: tests/eval/results.json. Reproduce with uv run pytest -m eval -v.
